# Terraria AI Companion

目标是让独立 tModLoader 客户端中的真实玩家由 AI 控制，未来再接入 Python Agent。**M1.0 核心流程与 M1.1 修复版的失焦移动已由用户实测通过。**

## 当前功能

- 在单人世界中按 **P** 切换自动右移；可在“设置 → 控制 → Mod 控制”中重新绑定。
- 默认关闭。开启时覆盖水平输入，关闭时不再写入控制字段，由原生机制减速；手动右移仍会继续生效。
- M1.1 实验版 `0.1.2` 每次开启最多持续 **10 秒**。仅自动模式有效时绕过单人失焦暂停、临时关闭后台休眠，并通过 `PostUpdateRunSpeeds()` 注入水平输入；关闭后恢复原有休眠设置。菜单暂停机制保持原样。
- 进入世界、离开世界、死亡和卸载时清除自动模式。不保存开关状态。
- 不修改位置或速度，不创建 NPC 或额外 Player。

**验证状态：M1.0 用户实测通过。M1.1 基线 `0.1.1` 失焦暂停；修复版 `0.1.2` 已在 tModLoader 2026.08.3.0 编译打包成功，收尾重新构建仍为 0 错误、0 警告。用户确认失焦后持续右移，约 10 秒后结束控制并恢复失焦暂停；日志也确认两轮约 10 秒自动关闭。修复版提前关闭、手动恢复及退出重进、死亡和卸载清理仍待单独确认。**

## 构建和测试

当前安装目录为 `D:\steam\steamapps\common\tModLoader`。在 PowerShell 中执行：

```powershell
$tml = 'D:\steam\steamapps\common\tModLoader'
$repo = 'D:\Agent Project\terraria-ai-companion'
Push-Location $tml
try {
    & "$tml\dotnet\dotnet.exe" "$tml\tModLoader.dll" -server -build "$repo\CompanionBridge" -tmlsavedirectory "$repo\.local\tmodloader"
} finally {
    Pop-Location
}
```

产物为 `.local/tmodloader/Mods/CompanionBridge.tmod`。使用隔离的测试配置启动游戏，不使用原有角色或存档：

```powershell
Push-Location $tml
try {
    & "$tml\start-tModLoader.bat" -tmlsavedirectory "$repo\.local\tmodloader"
} finally {
    Pop-Location
}
```

确认 CompanionBridge 已启用，先到“设置 → 控制 → Mod 控制”，找到“切换自动向右移动”，确认已绑定 **P**；若为空，请手动绑定。这里与“模组配置”是不同入口，本 Mod 没有配置选项属于正常情况。

新建测试角色和单人测试世界，在安全平地按 P，观察向右移动；再次按 P，松开方向键，观察减速停止。再测试 A/D 手动移动、退出重进和死亡复活。完整验收表见 [开发说明](docs/DEVELOPMENT.md)。

## 范围和限制

仅使用一个客户端和单人世界；自动模式只接管左右输入，其他手动输入保留。墙壁、地形和原生状态效果仍可能阻止移动。自动模式开启时不要在危险地形测试；输入文字时不会通过快捷键切换模式，但本原型没有单独暂停自动移动的聊天逻辑。

## M1.1 人工实验

先保存并完全退出游戏，再按上文构建、启动。在模组列表确认版本为 **0.1.2**，避免误测旧版；窗口化或无边框显示，准备至少能安全右移 10 秒的普通平地。

1. 确认“自动暂停”关闭（目前测试配置已关闭）；不要打开暂停菜单、聊天或背包，也先不要最小化窗口。
2. 前台按 P 开启，确认右移，立即 Alt+Tab 到其他应用。
3. 让游戏窗口保持可见，观察约 **3 秒**：是否继续右移、是否整个画面暂停。
4. 在 10 秒总时限前切回游戏，按 P 关闭，松开 A/D，确认停止，再验证手动操作。
5. 另开一轮失焦后等待超过 10 秒再切回，确认已自动关闭、没有恢复旧的移动指令；此时单人游戏可能再次按原生机制失焦暂停，属于实验结束后的预期行为。

请反馈“失焦继续移动 / 停止移动 / 整个游戏暂停”，以及切回后 P 关闭和手动操作是否正常。失焦前的短暂惯性不算持续移动；若返回时已有超时提示，不要马上按 P（那会重新开启）。当前修复不会伪造 `Main.hasFocus` 或修改“自动暂停”配置，只在自动模式有效期间绕过指定失焦暂停分支。若游戏线程完全停止调度，时限只能在下一次更新时执行。

尚未实现或验证：第二客户端、联机、更长时间或最小化窗口下的失焦运行、Python/IPC、LLM、寻路、战斗、背包和装备操作。当前 IL 补丁针对上述 tModLoader 版本，升级后需重新核对。
