# Server AI 地图记忆

`query_map` 读取服务器 AI 已积累的持久化地图近似知识。它不是实时 Tile 查询、摄像机画面或 Terraria 原生光照图，也不能单独批准导航或世界修改。

地图按 World UUID 与 AI Character ID 绑定，并随世界角色档案提交。地图数据按 Tile 保存一个字节状态：未知、已知非阻挡、实心、平台、水、岩浆、蜂蜜或微光。它不是完整 Tile/物体地图，不保留墙、家具、Frame 或逐格观察时间。

## 揭示模型

服务器 AI 运行时在角色有效、存活且未隔离时更新地图；默认每 15 个游戏更新检查一次，以角色中心附近 120×68 Tile 区域为采样范围。可见性是服务器近似，不等价于原生玩家视野：

- 以中间实心 Tile 遮挡的格线视线判断目标是否可见。
- 角色附近 4 Tile 内可揭示；白天符合地表开口条件的格子可视为日光可见。
- 当前支持的原版火把可在视线无遮挡时提供 14 Tile 范围的近似照明。
- 不模拟原生光照衰减、彩色光、液体吸收、装备/手持光、其他灯具或 Mod 光照钩子。

地图只记录实际采样区域，不沿移动/传送路径插值。成功动作可能触发目标区域重采样；未重新观察的人类或 Mod 修改不会自动刷新旧格。服务器暂停更新时，地图不按墙钟推进。

## 查询

`query_map` 通过 Server AI 能力 `server_ai_map_v1` 开放，仅适用于独立服务器 AI Player。支持：

- `overview`：世界级粗略概览，按统一 cellSize 聚合，供战略定位。
- `region`：围绕指定或当前角色 Tile 坐标读取局部区域，可设置宽、高和 `cellSize`；使用 `cellSize=1` 查看单 Tile 状态。

具体参数范围和返回字段以 `python/atomic_operations.py` 的 Schema/描述及当前能力握手为准。查询只读取已存内存地图，不访问 `Main.tile` 补全未知格，也不会隐式揭示或刷新区域。

返回行使用字符概览：`?` 未知、空格已知非阻挡、`#` 实心、`=` 平台、`~` 水、`L` 岩浆、`H` 蜂蜜、`S` 微光；`:` 表示混合或部分已知单元。液体符号表示该聚合单元内存在液体，不代表满格覆盖。响应同时包含原点、聚合尺寸、探索比例和 last-known 语义。

## 限制

- 地图是持久化探索记忆，不保证格子仍保持原状。
- 未知、未加载和从未采样不能视为空气。
- 近似可见性不代表玩家真实视线、光照或可交互性。
- 世界回滚、复制相同 UUID 的世界或更换保存根时，必须考虑角色档案身份；地图不是可独立迁移的世界文件。
- 高频查询或揭示的成本应按实际场景评估；当前文档不宣称完成最大世界规模压力验收。
