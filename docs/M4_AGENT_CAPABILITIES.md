# Terraria AI Companion --- M4 Agent Capabilities

**版本：** 1.0\
**对应阶段：** M4.1～M4.6\
**最终实现基线：** `6313b79`

本文从 Agent 使用者视角描述 M4
完成后已经建立的能力、调用边界和验证状态。

本文描述的是运行时具备的能力，不代表真实模型已经能够自主、稳定地使用全部能力。

------------------------------------------------------------------------

## 1. 总体定位

M4 完成后，Terraria AI Companion
已经从以单次原子操作为主的执行系统，发展为具有多尺度环境观察、有限长距离导航、运动能力适配和安全恢复机制的具身执行系统。

主要能力：

-   观察角色周围及更大范围的地形。
-   查询历史探索地图。
-   识别静态地形和部分动态危险。
-   根据已验证运动能力规划路线。
-   执行连续长距离导航。
-   在可恢复偏差后重新规划。
-   通过原生游戏证据确认动作完成和输入释放。

它仍然不是完整的自主生存或战斗 Agent。

## 2. 环境观察能力

### 2.1 近场精细观察：L0

默认范围：45×29 Tile。

可获取： - 实心地形。 - 空气。 - 平台、半砖和斜坡。 - 局部支撑与净空。 -
危险 Tile。 - 附近对象。 - 落脚与部分操作候选。

L0 是当前导航和动作执行的精细空间事实来源。

### 2.2 实时区域观察：L1

默认范围：120×68 Tile，最多 8192 格。

可获取： - 更大范围的地形几何。 - 对象与资源摘要。 - 危险分布。 -
未知和未采样覆盖信息。

L1 主要帮助 Agent 在执行动作前形成更大范围的环境认识。

限制： - 不替代 L0 的精细物理判断。 - 不直接承诺角色身体可达。 -
不直接生成可执行的采矿目标。 - 受范围、节点和时间预算限制。 -
可能返回部分采样。

### 2.3 历史探索地图：L2

复用现有 AI Map V1。

主要作用： - 查询历史探索信息。 - 获取较远区域的粗粒度历史先验。 - 帮助
Agent 避免重复探索。

限制： - 历史状态不等于当前实时状态。 - 不能用历史地图直接批准导航。 -
不能将历史空气或地形信息视为当前事实。

## 3. 导航与移动能力

### 3.1 基础导航

运行时支持： - 普通移动。 - 跳跃。 - 落地与支撑验证。 -
二维落脚区域搜索。 - 路线分段执行。 - 当前地形复核。

### 3.2 长距离行程

Navigation Trip 支持： - 路线前缀接续。 - 有界退让。 - 动态重新规划。 -
重复状态检测。 - 累计预算管理。

一次导航动作可以跨越多个局部规划窗口，不要求模型为每一个小移动重新发出指令。

### 3.3 安全恢复

发生可恢复路线偏差时： 1. 释放旧输入。 2. 观察当前游戏状态。 3.
确认安全停稳。 4. 重新规划。 5. 在有界次数内继续原导航动作。

身份变化、不可恢复失败、未知释放状态等情况仍然会终止执行。

### 3.4 运动能力适配

目前已经验证： - Basic。 - 原版 Swiftness。

能力变化会导致旧计划失效，并在同一动作内进行安全重规划。

不支持任意 Mod、特殊运动效果和所有装备组合。

## 4. 环境危险感知

### 4.1 静态危险

可识别局部场景中的危险 Tile 和相关环境事实。

### 4.2 动态实体

NPC 和敌对弹幕可以提供： - 观察身份。 - 观察 Tick。 - 包围盒。 -
原生速度。 - 弹幕额外更新次数。 - 有限时间的接触推断。

当前使用 12 游戏 Tick 的匀速包围盒接触推断。

这不是 Terraria 原生 AI 行为模拟，也不代表能够准确预测所有攻击或伤害。

## 5. 环境光照

当前专用服务器无法提供可信的原生实时亮度数据。

接口会明确返回光照不可用。

因此当前不具备： - 7×7 动态光照采样。 - 可靠的平均亮度和最低亮度判断。 -
根据光照自动插火把。 - 放置火把后的实时光照改善验证。

后续可以研究图形客户端光照采集，但不属于当前 M4 已完成能力。

## 6. 执行结果与安全边界

M4 继续依赖 M1～M3 已有的动作生命周期和原生执行契约。

包括： - 动作身份。 - 世界和 Actor 身份校验。 - 输入租约。 -
取消和终态。 - 输入释放证据。 - 实际游戏状态验证。

模型收到工具返回值，不等于游戏目标已经完成。

程序执行完成、导航动作完成和最终游戏目标完成是不同概念。

## 8. 当前系统尚未证明什么

M4 建立了执行和观察基础，但没有证明真实模型能够：

-   独立选择正确的远距离探索目标。
-   稳定理解大范围区域信息。
-   在复杂洞穴中持续规划。
-   自主决定何时战斗或撤退。
-   根据黑暗程度自动照明。
-   完成连续采矿、建造和生存任务。

这些需要 M5 完成后的真实模型与图形客户端综合验收。

## 9. 后续验证方向

M5 完成后，建议通过递进任务验证整个 Agent：

1.  基础环境观察。
2.  自主选择探索方向。
3.  连续导航与长距离移动。
4.  遇到动态地形变化后恢复。
5.  发现资源并完成有限采集。
6.  多步骤目标执行与结果报告。

记录模型决策、Lua 程序、原子 API、导航轨迹、原生游戏状态和最终结果。
