# R3 自主探索实现与验收

玩家明确委托探索时，Agent 用 `schedule_exploration` 登记一次有界往返。例如 `{"radiusTiles":24,"maxSegments":12,"allowDig":false}`。半径为 4–64 Tile，外出尝试上限为 1–64 段，整次行程上限为 3600 次游戏更新。Lua 也可通过 `submit_task` 提交 `explore_frontier`。资源沿用实时场景观察和现有交互。[C5 委托规格](R3_C5_AUTONOMOUS_EXPLORATION_SPEC.md) · [C6 地图规格](R3_C6_EXPLORATION_MAP_SPEC.md)

| 阶段 | 实现 | 定向验证 |
|---|---|---|
| P0 边界识别 | 在 AiMap 中提取已知开放格与世界内未知四邻的边界。窗口边缘补读一格，连续边界跨块聚类。 | 固定地图覆盖世界边、裁剪边、封墙和 32 Tile 块缝。只读检查的地图增量为零。 |
| P1 地图记忆 | AiMap 继续作为唯一持久化地形记忆。v2 文件兼容 v1，增加稀疏块版本和观测时间。边界簇按窗口及邻圈版本缓存。 | AiMap 18 项检查及跨进程恢复通过，地图协议 3 项通过。8400×2400 回放中，局部成本查询读 100 格，分片与一次算完选中同一段。 |
| P2 通行与观察 | 在有支撑、身体净空足够的站位间分别搜索去程和返程。干路、浅水、跳跃和可选单格清障按更新数计价。返程须能纯移动完成。按预计新增格数除以往返及观察更新数排序。 | 假时钟和可注入能力覆盖单向井、液体、挖掘报价和派发前新增障碍。缺少回攀能力时无下落候选。 |
| P3 行程与回执 | GoalStore、TaskCoordinator 与 Lua 共用原生根任务。每段结束观察并重算，候选摘要最多三项。已稳定落地的失败入口按方向冷却。新增覆盖、实际返回、安全停稳和释放输入共同决定成功。 | 双岔路第一支受阻后改走第二支，实际地图新增 1 格，重复外出边 0 条，模拟返程 1/1，约 0.78 格/百次模拟移动更新。该夹具暂未显示引入拓扑图的收益。 |

## 当前导航与往返验证

Frontier 从地图记忆中选出能看见未知格的观察站位，按预计增益和距离分批送交导航，每批最多三个站位。同批候选共享起点的物理预测。导航用当前角色的位置、速度、额外跳跃和飞行资源模拟去程，再从预测落地状态模拟返回原锚点。探索按已验证路线的输入帧数计算往返成本，派发选中路线，并在每个动作衔接时复查去程和返程的地形。打开 `allowDig` 时，原有通行成本图仍可建议单格清障，返程只允许移动。

搜索按游戏更新分片。完整轨迹须留在已知窗口内，最终落区须能安全停稳。局部搜索耗尽预算时报告 `exploration_route_unconfirmed`。回执记录规划分片数、最长分片耗时、候选去返程验证次数、实际锚点偏差与新增格数。目前观察站位仍以平坦支撑面为准，路线可使用已建模的跑跳、额外跳跃与飞行装备。原版基础钩还可用于 9–12 格的高差。探索分别验证去程和返程的发射位置、已知射线、锚点、牵引和脱钩后的落区。取下钩爪或改变锚点会使已有钩爪报价失效。

在 2026.09.3.1 引擎的隔离世界中，跨七格沟往返的锚点横向偏差为 0.36 px。八格高台场景中，基础角色留在原地，装备云瓶后新增 1 格并返回，偏差为 0.09 px。单向井有三次去程验证成功，返程验证成功数和下行派发数均为零。途中移除对岸的场景结束于原岸，新增覆盖为零。

同井对照夹具在井底留一格待观察地形，并在井口上方保留一个实体锚点。带基础钩时，角色下井、观测、实际挂钩上升并返回，横向偏差小于 1 px。无钩时须保持零下行派发。该对照可用下方专服脚本的 `-Frontier -Scenes frontier_hook,frontier_nohook` 单独运行。

分片的 2 ms 是检查工作之间使用的软预算。上述云瓶探索一次往返用了 1041 个规划分片，最长 16.8 ms；单向井用了 1365 个规划分片。回执中的 `planningSlices` 与 `maxPlanningSliceMs` 可以区分总规划延迟与单帧开销。

## 复核入口

自由探索盲测使用种子 `20261127` 新生成的小世界，每次从新角色出生点开始。使用自然地形测试宿主推动无人专服的游戏帧，期间排除非城镇 NPC，不注入行进路线。两名独立 MCP 驾驶者均只收到“去附近探索”和连接说明。第一次向右走了约 32 格，段末广域扫描超时。增加近区重试后，第二名驾驶者先发现铁矿，自选继续向右寻找通道。四段导航实际推进 2038 世界像素，途中记录锡矿，在 `open_descent` 处停下。左侧落点有近期足迹，下方落点没有近期足迹且周围 9×9 格中有 38 格未知。四段均确认到达和输入释放。此次没有下行或采集动作。两次驾驶者不同，位移只描述各自的选择。

### 简化定向探索后的同场对照

取同一份自然世界存档，给两个独立角色相同的出生位置、初始地图（4301 个已知格）和装备。经 MCP 各调用一次 `explore`，均指定向右和相同的 objective，省略 seek。地图格数来自同一世界的 AiMap overview；规划时间和执行更新数取自实际导航子任务的回执。

| 单次调用 | 旧版 `7ba0da7` | 简化后 |
|---|---:|---:|
| 向右实际位移 | 0 格 | 191.0 格 |
| 地图新增已知格 | 0 | 9150 |
| 观察到的矿石 | 铁 | 铁、锡 |
| 完成导航段数 / 重复失败次数 | 0 / 0 | 6 / 0 |
| 原生导航规划耗时 / 执行更新数 | 0 ms / 0 | 122.4 ms / 1701 |
| 工具调用耗时 | 0.13 秒 | 29.88 秒 |
| 结束原因 | 起点发现铁矿 | 达到 6 段上限 |
| 释放证据 | 未派发移动，租约安全释放 | 6 段均确认释放，租约安全释放 |

另一次自然世界盲测只给新驾驶者“去附近探索”和 MCP 连接说明。它先查询现场，选择向右走满 6 段（191 格）。段末观察给出向下落点、近期足迹和下降通道。它接连两次自行选择向下，共下降 22 格，最后再次查看现场，记录锡、铁和银。三次调用均未指定 seek，均以段数预算结束。全程 18 段导航完成并确认释放，地图已知格从 4301 增至 16792。此次没有采矿，也没有验证抵达地下生物群系。自然场景测试关闭了非城镇 NPC。

方向探索另有洞穴专服用例。用当前源码构建 CompanionBridge，向 `tests/verify_server_ai_native.ps1` 传 `-DirectionalExplore cave -PackagePath <本次构建包>`。脚本客户端经 MCP 读取真实场景，用方向探索进入洞道，通过叉口观察给出的世界像素坐标实走两支。回执保存在独立世界副本目录的 `external-explore.json`。带 `-LiveModel` 时改由已配置模型根据自然语言委托选路，`autonomy.json` 记录实际决定和位置。

- 边界和清障成本回放使用 `./tests/run_frontier_replay.ps1`。局部物理规划和精确返程用例使用 `./tests/run_csharp_tests.ps1 -PlannerOnly`。
- 使用 `./scripts/build-companion.ps1 -OutputPath .local/frontier-motion-build` 构建当前源码。运行 `./tests/verify_navigation_recovery_native.ps1 -PackagePath .local/frontier-motion-build/Mods/CompanionBridge.tmod -Frontier` 验证普通到点跨沟、探索跨沟往返、同一高台换装云瓶前后的可达性、有钩与无钩的同井返程、单向井和途中移除对岸。每次运行使用独立世界副本，输出目录含任务回执与运动轨迹。
- 使用同一专服脚本和包，传入 `-ExtraJump -Scenes cloud_root,cloud_chain` 或 `-Wings -Scenes bone_chain` 验证装备动作和连续高台。
