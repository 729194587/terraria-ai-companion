# 垂直导航：0.1.63 隔离验证

本轮基于 `2c70ec8` / `codex/g85-server-ai-perception`，沿用 Draft PR #25。复用已有导航器，只补齐**同 X 区间内的原地上跳候选**。原有未跟踪文件、runs 和图形实机证据均保留，未部署现用 profile、未启动/停止用户游戏、未调用模型；所有原生执行发生在复制世界的无客户端专用进程。

## 核实与最小修复

**观察**：`StateSpacePlanner` 已有二维 LandingRegion、跳跃 hold 枚举、可行完整路线的预算回退和安全部分路线；`PhysicsSimulator` 已模拟跳跃、碰撞、下降限制、制动与稳定支撑。`NavigationTask` 已从实际支撑检查点重新规划，保留四次无进展/256 动作上限、落地确认和 unknown；`NativeNavigation` 保留普通运动 profile、生命变化和 50ms 监督。Server AI 的区域动作已贯通原游戏线程输入边界、身份绑定、终态与 known 输入释放，未增加新动作。

**实验结果：可复现缺口**：32px 宽竖井、角色宽20px、上方64px水平平台、4px宽目标 X 区间。旧规划器只枚举左右输入；预测器要求跳跃沿输入方向至少横移24px，竖井里任何左右候选都达不到。离线和原生均失败。原生只扩展1节点，12.5953ms，`TimeBudgetReached=false`，零动作执行，安全原地停稳并释放输入；不是目标选择错误、预算不足或物理预测偏差。原始回执位于 `summary.json.baselineShaft` 指向的 events.jsonl 行。

**选择**：仅在当前左边缘已位于目标 X 闭区间、目标脚底至少高4px时，规划器加入零方向跳跃；预测器要求这种候选最终落在至少高4px的安全支撑上。返回原高度的空跳仍拒绝，避免搜索循环。所有候选仍执行同一逐帧安全检查和制动尾段。横向目标、左右候选、64px下降上限、危险/未知限制、落点公差和预算均保留。没有新增 jump 原子操作、传送、修改垂直速度或失败后重试。

**实验结果：修复后**：两方向竖井均一段跳跃到达，X 不变、预测位置误差0；真实运动边界记录到 Jump 输入，所有该段采样的 Left/Right=false。实际停稳发生在 Stop 清理之前，`velocityBeforeRelease=(0,0)`。结束回执确认同 world/generation/slot 的输入释放。

## 验证与证据

- 新离线矩阵：14种配置、17个目标段；另核验零方向上升预测和同层空跳拒绝。任务使用生产默认32扩展/25ms；单独诊断计划使用500ms去除JIT噪声，并非更改生产预算。
- 既有定向：`-NavigationOnly`（规划/运动、落地确认、危险、取消、分代与玩家hook）、`-LandingOnly`（区域协议/到达/续约/结束证据）；11个Python用例（服务器落脚、真实C# TCP/Agent集成、能力门禁、取消及错误回执）。
- IPC/原子/读取/适配/聊天定向断言分别45/40/57/97/30；最终正式包71项IL检查。构建0错误、0警告。**未运行全量测试。**
- 最终同包原生：38场配置全部符合预期，44次区域动作中34次完成、10次预期失败；全部终态 known、输入释放及绑定核验通过。每场最终均真实安全停稳，未以清理时的水平制动伪造自然到达。
- 原生脚本同轮还执行旧读取/选择、横向导航、物品、挖掘、取消和进程生命周期清理；这些不计入38场矩阵。

复现命令见[二维落脚文档](../../SERVER_AI_LANDING_REGION.md#0163同-x-垂直跳台补齐)；实际最终包为 `.local/vertical-confirmed-build/Mods/CompanionBridge.tmod`，哈希见[manifest](manifest.json)中 `packageSHA256.confirmed`。归档包括各次实际包、源世界、Lua程序、Worker事件、原始回执、逐帧轨迹、测试/构建日志，以及字节校验脚本。manifest 中每项SHA同时与源文件和ZIP entry核验；`summary.json` 与 `matrix.md` 是明确标记的派生报告，没有改写原始证据。

保留的先期失败：旧预测器的竖井失败；记录器未记录首帧终态导致外层等待轨迹超时；输入采样错误要求运动边界tick等于更新后tick，导致两个已完成竖井动作被测试判失败；沙箱loopback受阻和包版本断言未同步。各包及运行分别标识，不将先期失败与最终通过混合。记录器现在按 `Tick → Main.Update → Observe` 同步帧关联真实输入，保存实际采样tick和更新后tick，首帧失败也有真实终态帧。

## 剩余边界

这是当前基本运动 profile 的局部导航证据，不是任意地形可靠可达保证。精确窄X区间的横向制动仍可能耗尽进展预算；绕障需要暂时远离目标时仍可能受局部搜索/跨度/进展限制。未支持按Down穿平台、任意远程全局路径、超64px单边下降、未知/危险覆盖、非普通运动profile或以斜面作为最终区域。原地上跳仅用于目标X区间内的上升，不承诺在区间外发现所有中间垂直跳台策略。

本轮未验证真实模型自主选点、图形Host & Play、真人/敌怪同场与远端同步。观察到安全平台只证明它是候选，仍需当次规划和执行确认；局部失败保留原始原因，不能从失败统计推断唯一根因或全局不可达。
