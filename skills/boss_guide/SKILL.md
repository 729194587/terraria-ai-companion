# Boss Guide

## Boss Summoning

| Boss | 召唤方式与条件 |
|---|---|
| 史莱姆王 King Slime | 任意地点使用史莱姆王冠；史莱姆雨期间击杀 150 只史莱姆（此前已击败则为 75 只）也会出现；还可能在地图两侧地表草地自然生成。 |
| 克苏鲁之眼 Eye of Cthulhu | 夜晚使用可疑眼球；自然生成需至少一名玩家有 200 最大生命、11 防御，世界有至少 4 名城镇 NPC，并满足 Boss 进度条件。 |
| 世界吞噬怪 Eater of Worlds | 在腐化之地使用蠕虫诱饵，或破坏三个暗影珠。仅限腐化世界。 |
| 克苏鲁之脑 Brain of Cthulhu | 在猩红之地使用血腥脊椎，或破坏三个猩红之心。仅限猩红世界。 |
| 蜂王 Queen Bee | 在地下丛林蜂巢破坏幼虫，或在丛林使用憎恶之蜂。 |
| 骷髅王 Skeletron | 夜晚与地牢入口的老人交谈，选择诅咒选项。 |
| 鹿角怪 Deerclops | 在雪原或冰雪生物群系使用鹿华；地表雪原暴风雪期间午夜也可能自然生成，需满足生命/防御及附近无城镇 NPC 等条件。 |
| 血肉墙 Wall of Flesh | 在地狱将向导巫毒娃娃投入熔岩；向导必须存活。 |
| 史莱姆皇后 Queen Slime | 在神圣之地使用明胶水晶。 |
| 双子魔眼 The Twins | 夜晚使用机械魔眼；困难模式中也可能自然生成。 |
| 毁灭者 The Destroyer | 夜晚使用机械蠕虫；困难模式中也可能自然生成。 |
| 机械骷髅王 Skeletron Prime | 夜晚使用机械骷髅头；困难模式中也可能自然生成。 |
| 世纪之花 Plantera | 击败全部三个机械 Boss 后，破坏地下丛林的世纪之花花苞。 |
| 石巨人 Golem | 击败世纪之花后，在丛林神庙的丛林蜥蜴祭坛使用丛林蜥蜴电池。 |
| 猪龙鱼公爵 Duke Fishron | 在海洋使用松露虫作为鱼饵钓鱼。 |
| 光之女皇 Empress of Light | 击败世纪之花后，夜间在地表神圣之地捕捉并击杀七彩草蛉；白天击杀会进入强化状态。 |
| 拜月教邪教徒 Lunatic Cultist | 击败石巨人后，前往地牢入口击败拜月教信徒。 |
| 月亮领主 Moon Lord | 击败拜月教邪教徒后摧毁四座天界柱；也可使用天界符召唤。 |

## Summoning Conditions

- 可疑眼球、机械魔眼、机械蠕虫和机械骷髅头只能在夜晚使用。
- 蠕虫诱饵和血腥脊椎必须在对应世界邪恶区域使用。
- 破坏暗影珠或猩红之心会触发对应世界邪恶 Boss 的召唤条件。
- 机械 Boss 的自然生成只会在困难模式发生；击败一个机械 Boss 后，其他机械 Boss 的自然生成概率提高。
- 世纪之花必须在三个机械 Boss 全部击败后才会生成花苞。
- 石巨人需要击败世纪之花并取得神庙钥匙才能进入神庙。
- 拜月教邪教徒需要先击败石巨人。
- 月亮领主可在四座天界柱全部摧毁后出现，也可以在击败拜月教邪教徒后使用天界符召唤。

## Boss Preparation

### Buffs

根据职业、进度和战斗难度准备：

- **药水**：铁皮、再生、迅捷、耐力、生命力、怒气、暴怒等。
- **食物**：准备能提供 Well Fed 等增益的食物。
- **通用增益设施**：篝火、心形吊灯、蜂蜜池、巴斯雕像。
- **职业增益设施**：
  - 战士：磨刀石。
  - 射手：弹药箱。
  - 法师：水晶球。
  - 召唤师：附魔桌、战争桌。

按当前职业和可获得设施选择，不要求每场战斗全部准备。

### Boss Arena

常规 Boss 场地可采用多层平台：

- 建造 3～4 层长平台。
- 平台垂直间隔约 20～30 格。
- 放置篝火和心形吊灯。
- 根据职业放置对应增益设施。
- 保留足够的横向移动空间。

特殊 Boss 可能需要不同场地，应结合召唤地点和战斗空间调整。
