# Event Guide

## Natural Events

| 事件 | 触发条件 |
|---|---|
| 血月 Blood Moon | 夜晚随机发生；至少一名玩家最大生命值超过 120，且当晚不是新月。 |
| 史莱姆雨 Slime Rain | 白天随机发生；受玩家最大生命值和 Boss 进度影响。 |
| 哥布林军队 Goblin Army | 至少破坏一个暗影珠或猩红之心，且至少一名玩家最大生命值达到 200；在黎明进行随机判定。 |
| 海盗入侵 Pirate Invasion | 困难模式且至少一名玩家最大生命值达到 200 后，有概率自然发生。 |
| 日食 Solar Eclipse | 困难模式白天有概率自然发生。 |

## Summonable Events

| 事件 | 召唤方式与条件 |
|---|---|
| 血月 Blood Moon | 夜晚使用血泪。 |
| 哥布林军队 Goblin Army | 使用哥布林战旗；至少一名玩家最大生命值达到 200，且当前没有其他入侵事件。 |
| 旧日军团 Old One's Army | 在埃特尼亚水晶座放置埃特尼亚水晶；两侧需要满足场地地形要求。 |
| 雪人军团 Frost Legion | 困难模式使用雪球仪；至少一名玩家最大生命值达到 200。 |
| 海盗入侵 Pirate Invasion | 困难模式使用海盗地图；至少一名玩家最大生命值达到 200。 |
| 日食 Solar Eclipse | 困难模式白天使用日耀碑牌。 |
| 南瓜月 Pumpkin Moon | 夜晚使用南瓜月勋章。 |
| 霜月 Frost Moon | 夜晚使用调皮礼物。 |

## Special Events

| 事件 | 触发条件 |
|---|---|
| 火星暴乱 Martian Madness | 击败石巨人后，在太空层让火星探测器发现玩家并成功逃离，使其离开屏幕。 |
| 月亮事件 Lunar Events | 击败拜月教邪教徒后自动开始。 |
| 派对 Party | 派对女孩入住后可由她启动派对；也可能随机发生。 |

## Event Notes

- 血泪只能在夜晚使用。
- 哥布林战旗要求至少一名玩家最大生命值达到 200。
- 雪球仪和海盗地图只能在困难模式使用，且要求至少一名玩家最大生命值达到 200。
- 日耀碑牌只能在困难模式白天使用。
- 南瓜月勋章和调皮礼物只能在夜晚使用。
- 火星探测器被击败或未能成功逃离时，不会触发火星暴乱。
- 入侵类事件需要玩家处于事件活动范围内，远离入侵区域时敌怪可能无法正常生成。

## Old One's Army Arena

旧日军团需要专门场地：

- 将埃特尼亚水晶座放置在平坦、开阔的区域。
- 水晶座左右两侧都需要保留足够的平坦地面供敌人行进。
- 不要用平台、墙体或其他障碍阻断事件要求的地面路径。
- 放置水晶前确认两侧地形符合召唤要求。
