# Game Progression

Terraria 的发展围绕探索、资源收集、装备升级和 Boss 挑战展开。Boss 击败情况决定重要世界变化，但同一阶段通常存在多条可选路线。根据当前世界进度和角色装备决定下一步，不必机械遵循固定顺序。

## 阶段与发展路线

| 阶段        | 探索与发育                                          | Boss 与阶段解锁                                 |
| --------- | ---------------------------------------------- | ------------------------------------------ |
| 开荒        | 探索森林、沙漠、雪原和地下洞穴；寻找生命水晶、魔力水晶、宝箱、移动配饰和基础矿物；建立基地。 | 准备挑战克苏鲁之眼。史莱姆王是可选挑战。                       |
| 早期 Boss   | 继续探索地下和世界邪恶区域，收集矿物、宝箱装备及永久增益。                  | 击败克苏鲁之眼后获得邪恶矿物相关发展机会；准备世界吞噬怪或克苏鲁之脑。        |
| 邪恶 Boss 后 | 收集魔矿/猩红矿及对应 Boss 材料，制作邪恶镐；探索陨石、地下丛林和蜂巢。        | 可挑战蜂王；准备骷髅王。击败邪恶 Boss 解锁狱石采集能力。            |
| 地牢与地狱     | 击败骷髅王后探索地牢，寻找暗影钥匙和特殊装备；探索地狱废屋、狱石矿脉及暗影箱。        | 制作熔岩镐和狱石装备，准备血肉墙。骷髅王是主线必经节点，也是正常探索地牢的前置条件。 |
| 困难模式初期    | 观察神圣与邪恶区域变化；破坏祭坛，逐级采集困难模式矿物，升级装备。              | 挑战双子魔眼、毁灭者和机械骷髅王。                          |
| 机械 Boss 后 | 寻找生命果、叶绿矿和世纪之花花苞；继续探索地下丛林。                     | 击败三个不同机械 Boss 后生成世纪之花花苞。                   |
| 世纪之花与石巨人  | 重访地下丛林和地牢，寻找新敌怪、灵气和宝箱；探索丛林神庙。                  | 击败世纪之花取得神庙钥匙，进入神庙挑战石巨人。                    |
| 终局准备与支线   | 根据职业和装备情况挑战猪龙鱼公爵、光之女皇、火星暴乱等可选内容，完善终局装备。        | 石巨人与骷髅王击败后挑战邪教徒；击败后进入天界事件，最终挑战月亮领主。        |
| 月亮领主后     | 收集终局装备、完成事件、图鉴、建筑和其他个人目标。                      | 主线完成，自由发展。                                 |

## 重要进度关系

- 世界吞噬怪和克苏鲁之脑取决于世界邪恶类型。
- 蜂王和史莱姆王属于可选 Boss，不是主线硬性前置。
- 骷髅王是正常主线探索地牢的必经节点。
- 困难模式由首次击败血肉墙触发。
- 生命果在首次击败机械 Boss 后开始生成。
- 世纪之花花苞在三个不同机械 Boss 全部击败后生成。
- 世纪之花击败后解锁丛林神庙。
- 石巨人与骷髅王击败后，地牢入口出现拜月教邪教徒。

## 值得重访的区域

| 区域      | 重访时机                  |
| ------- | --------------------- |
| 地下洞穴    | 发现新的探索能力或需要更多资源时      |
| 腐化/猩红区域 | 需要对应矿物、材料或特殊掉落时       |
| 地狱废屋    | 获得暗影钥匙后开启暗影箱          |
| 地下丛林    | 机械 Boss 全部击败后寻找世纪之花花苞 |
| 地牢      | 世纪之花击败后寻找新敌怪和特殊奖励     |
| 丛林神庙    | 获得神庙钥匙后               |
