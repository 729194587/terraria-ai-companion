# NPC Guide

## NPC 到达条件

### 困难模式前

| NPC | 到达条件 |
|---|---|
| 向导 Guide | 世界初始 NPC |
| 商人 Merchant | 玩家随身钱币总额达到 50 银币 |
| 护士 Nurse | 商人已入住，玩家最大生命值超过 100 |
| 爆破专家 Demolitionist | 商人已入住，玩家持有爆炸物 |
| 染料商 Dye Trader | 持有染料相关物品，且已有足够城镇 NPC |
| 渔夫 Angler | 在海洋找到并唤醒沉睡渔夫 |
| 动物学家 Zoologist | 怪物图鉴完成度达到 10% |
| 军火商 Arms Dealer | 持有枪械或子弹 |
| 树妖 Dryad | 击败克苏鲁之眼、世界吞噬怪、克苏鲁之脑或骷髅王之一 |
| 酒馆老板 Tavernkeep | 击败世界吞噬怪或克苏鲁之脑后，找到并唤醒昏迷男子 |
| 发型师 Stylist | 在蜘蛛洞中找到并解救 |
| 高尔夫球手 Golfer | 在地下沙漠找到并解救 |
| 油漆工 Painter | 已有 8 名其他城镇 NPC |
| 哥布林工匠 Goblin Tinkerer | 击退哥布林军队后，在洞穴层找到并解救 |
| 巫医 Witch Doctor | 击败蜂王 |
| 布匹商 Clothier | 击败骷髅王 |
| 机械师 Mechanic | 击败骷髅王后，在地牢找到并解救 |
| 派对女孩 Party Girl | 已有 14 名其他城镇 NPC 后，有概率入住 |

### 困难模式

| NPC | 到达条件 |
|---|---|
| 巫师 Wizard | 在困难模式洞穴层找到并解救 |
| 税收官 Tax Collector | 在地狱找到受折磨的灵魂，使用净化粉转化 |
| 松露人 Truffle | 困难模式下，在地表发光蘑菇生物群系建造有效住宅 |
| 海盗 Pirate | 击败海盗入侵 |
| 蒸汽朋克人 Steampunker | 击败至少一个机械 Boss |
| 机器侠 Cyborg | 击败世纪之花 |
| 圣诞老人 Santa Claus | 击败霜月军团，且处于圣诞季 |
| 公主 Princess | 解锁其他所有可入住城镇 NPC（不包括城镇宠物和圣诞老人） |

### 特殊 NPC

| NPC | 出现方式 |
|---|---|
| 旅行商人 Traveling Merchant | 白天随机到访 |
| 骷髅商人 Skeleton Merchant | 地下随机出现 |
| 老人 Old Man | 初始出现在地牢入口；击败骷髅王后转变为布匹商 |

## 住宅与入住

- 普通城镇 NPC 需要有效且空置的住宅才能入住。
- 房间需要满足原生住宅判定，包括空间、背景墙、光源、桌面、座椅和入口等要求。
- NPC 死亡后，只要有有效空置住宅，通常可以重新入住。
- 已入住 NPC 的住宅可以通过住宅检查工具查询和重新分配。

## NPC 交互与交易

- 与 NPC 交谈可以查看对话、商店和可用服务。
- 商品库存和价格可能受到游戏进度、时间、生物群系及 NPC 幸福度影响。
- NPC 幸福度影响商品价格和晶塔出售条件。
- 哥布林工匠提供装备重铸及工匠作坊等服务。
- 护士提供生命恢复和减益治疗服务。
- 其他 NPC 的具体商品和服务以实际交互结果为准。
