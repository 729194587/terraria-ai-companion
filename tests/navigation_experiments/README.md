# 导航算法对照实验

基线为 `codex/r3-autonomous-exploration` 的 `2d2be0b`。在 9 个固定角色与地形组合中，生产导航在隔离专服实际到达 **6/9**。两次独立启动的结果一致。这是特意选取的边界场景，分母包含能力对照，同一地形可能出现多次，不能外推到自然世界。

单变量实验找到了两条默认局部搜索漏掉的模型路线。加密按跳时长采样解决了精确落点，滚动纵向碰撞窗口解决了翼跳高台。两条新增输入序列在原生服务器上都未能在目标带内停稳。精确落点能由生产导航以另一条路线到达。翼跳高台的真实可达性仍待证明。

## 方法与指标

- 每行重新创建地形、角色和搜索记忆。SurfaceGraph 最多交接 8 次，每次最多 96 个时间片，每片 512 单位图工作量。相同物理状态再次交接即停止并保留已验证前缀。局部搜索每次只生成一份路线。固定工作量对照去掉墙钟截止，保留生产采样、速度状态、损伤检查、搜索范围及物理验证。另有 `production_local` 实测原始 32 次展开 / 25 ms，以及 `production_surface` 实测原始 512 / 4 ms 切片。
- A1 保留每个经过物理探测的站位区间，沿用原有区间表示。A2 同步推导枚举列宽与像素距离。A3 只改变普通跳键持续时长的取样，二段跳触发和翼时序保持默认。A4 只移动碰撞窗口的 Y 锚点，保留 X 边界、邻域、单边帧数、状态搜索跨度和跌落伤害限制。窗口按当前源码的上边界及向下额外观察行构造。地形碰撞复用 SurfaceGraph 测试替身。
- 离线每条边从上一条边的实际执行终点出发，用 `PhysicsSimulator.Step` 重算每帧，检查完整状态相等和扫掠安全。另沿制动尾段检查至停稳，再回到执行交接点继续下一条边。专服只注入执行段输入，由真实 `Player.Update` 连续执行；检查起点、身份、连续 tick、终态支撑、速度、目标位置与输入释放。同一场景相同按键序列共享一次专服回放，配对行不作为独立重复样本。
- `FoundRoute` 和 `RouteKind` 分别记录是否规划出经回放确认的完整路线，以及完整、部分、无路线。82 行主实验中分别有 34、42、6 行。离线 `ActuallyArrived` 为 null。原生 `ActuallyArrived` 对应最后一帧的落点核验。`FalseNegative` 需要相同场景、起点和能力的成功见证；离线表使用模型见证，原生表使用实机见证；缺少见证时保留 null。局部组件漏解可以与闭环导航成功同时出现。
- `CandidateCount` 为图邻居尝试加局部运动候选尝试，包含被拒项。`ExpandedStates` 汇总图与嵌套物理搜索；不计静态站位探针。`ModelRejectionCount` 按主运动枚举返回的不安全预测计数，缓存命中仍计一次候选。`SearchTime` 为搜索毫秒数，排除回放。`SearchBudgetExit` 与路线完整性独立，预算退出时可能已持有完整路线。
- `ExecutionDeviation` 为执行段所有帧相对预测的最大二维位置误差，单位 px。`RecoverySuccess` 仅对发生恢复的闭环执行有值。预算、覆盖不足、预测拒绝、模型缺失及真实执行失败分别保留。唯一有独立几何证明的物理不可达对照为 `buried_goal`，整个目标身体都在连续实心地板内，且夹具禁止改地形。`unknown` 则在碰撞邻域读到未知 Tile。地形编辑由独立的 LocalTerrainPlanning 路径负责，未混入运动搜索对照。

## 对后续优化的建议

1. 优先核对翼推进和释放阶段的原生速度。逐帧比对 `wing_window` 与 `wing_high`，定位首次分歧，再评估扩大窗口后的执行收益。
2. 对重复交接、窄落点按需增加跳键时长采样，并保留闭环制动。精确夹具已能检测“找到路线但直接执行越过落点”的回归。
3. 空中重规划先复用偏移分叉，以相同偏差状态比较确认时间、失败边抑制和碰撞安全。新增专服对照可在原生飞行中记录同一边界状态，再分别驱动自然落地恢复和立即续接。A1 与 A2 目前只有成本变化，扩大自然地形样本后再决定默认值。

## 复现

仓库根目录、PowerShell 7、Python 3。专服另需匹配 [引擎配置](../../CompanionBridge/EngineProfiles.json) 的 tModLoader、测试世界及项目 Lua Python 环境。此次使用默认配置 2026.09.3.1 / Terraria 1.4.4.9。命令只运行导航专项。

```powershell
./tests/run_csharp_tests.ps1 -NavigationExperimentOutput tests/navigation_experiments/offline.json
./scripts/build-companion.ps1 -OutputPath .local/nav-experiment-build
./tests/verify_server_ai_direct_input_native.ps1 -TestScript navigation_experiments/native.py -PackagePath .local/nav-experiment-build/Mods/CompanionBridge.tmod
# 使用上一条命令输出的隔离 profile 目录替换 <profile>
python tests/navigation_experiments/compare.py --profile "<profile>"
```

已提交的数据可直接用 `python tests/navigation_experiments/compare.py` 复核。要检查固定工作量的重复性，再生成 `.local/nav-repeat.json`，并传入 `--repeat .local/nav-repeat.json`。每次离线运行都会重写指定输出和同名的 `.positions.json`、`.controls.json`。实机结果绑定输入文件 SHA-256，重新生成输入后应配套重跑实机。
